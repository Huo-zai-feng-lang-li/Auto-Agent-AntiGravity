# 模型完成通知焦点门禁 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 仅在模型完成事件已确认且 IDE 失去焦点时发送任务完成桌面通知。

**Architecture:** 在 `main_scripts/notification-policy.js` 放置无副作用的通知策略函数，集中判断通知开关、焦点和冷却期。`extension.js` 在 `TASK_COMPLETED` 回调中读取 VS Code 实时焦点状态并调用策略；模型完成状态机与 CDP 转发保持不变。

**Tech Stack:** Node.js CommonJS、VS Code Extension API、Node `assert` 集成测试、esbuild。

## Global Constraints

- 保持模型完成判定和 `TASK_COMPLETED` 事件链不变。
- 不新增依赖，不修改 WPF 通知渲染器。
- 使用最小改动，保留现有 5 秒通知冷却。
- 修改注入脚本时才需要 `node --check`; 本任务不修改注入脚本。
